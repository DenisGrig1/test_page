# FORMA — многостраничный сайт мебельной компании

Статический сайт для GitHub Pages. Не требует сборки, Node.js или сервера.

## Структура

- `index.html` — главная страница
- `catalog.html` — каталог мебели с поиском и фильтрами
- `reviews.html` — отзывы
- `contacts.html` — контакты и форма запроса
- `css/style.css` — общие стили
- `js/script.js` — меню, каталог, поиск, фильтры и форма
- `.github/workflows/deploy.yml` — GitHub Actions для публикации

## Важно про форму

GitHub Pages — статический хостинг. Форма не отправляет данные на сервер. Сейчас после заполнения она открывает почтовую программу посетителя с подготовленным письмом. Для полноценной отправки без почтовой программы потребуется подключить серверный сервис обработки форм.

## Изображения и шрифт

Для изображений используются внешние URL Unsplash, шрифт Manrope загружается через Google Fonts. Для их отображения требуется подключение к интернету.
